# Rickipedia — лабораторная работа 3

Второй экран с подробностями об элементах каталога по заданию ../assignment.docx.
Проект продолжает лабораторную №2.

## Возможности

- Шесть персонажей с локальными изображениями.
- Нажатие на карточку открывает крупный портрет, имя, статус, вид, ID,
  краткое описание и развёрнутый текст.
- Прокрутка, перенос текста, ограничение ширины на компьютере.
- Кнопка «Назад» возвращает к прежнему месту каталога.
- Прямой адрес `/#/home/character/2` открывает Морти.
- Некорректный ID показывает сообщение и кнопку к каталогу.
- Данные входят в проект; API не используется.

## Запуск и проверка

Flutter 3.47.4 / Dart 3.13.3 либо совместимая версия.

```powershell
flutter pub get
flutter run -d chrome
flutter analyze
flutter test
flutter build web --no-web-resources-cdn
```

Тесты проверяют каталог, все шесть переходов, возврат с сохранением прокрутки,
прямую ссылку, неверные ID, ширину 320 и 1100 px с масштабом текста 150%.
Проверена веб-версия. Android, iOS, macOS, Linux и Windows не собирались.

Исходные каталоги Windows и Linux находятся в `../platforms`, поскольку
создание ссылок плагинов на этой машине ограничено. Для настольной сборки
перенесите каталог платформы в корень `rickipedia` и подготовьте окружение
Flutter. В Windows потребуется поддержка symlink.

При проблемах с кириллицей в пути используйте свободную букву диска
в той же сессии PowerShell:

```powershell
subst L: (Get-Location).Path
Set-Location L:\
flutter analyze
flutter test
```

## Структура изменений

- `lib/app/features/details/character_details_screen.dart` — второй экран.
- `lib/app/features/home/character.dart` — биография и свойства статуса/вида.
- `lib/app/features/home/home_screen.dart` — нажатия на строки каталога.
- `lib/app/widgets/content_card.dart` — Hero для портрета.
- `lib/app/router/router.dart` — вложенный именованный маршрут
  `/home/character/:id`; выбор персонажа по ID из локального списка.
- `test/details_test.dart` — тесты второго экрана и навигации.

## Ресурсы

Методические указания: `../assignment.docx` из корня учебного проекта.
Портреты сохранены из лабораторной №2; источник:
https://rickandmortyapi.com/api/character/avatar/{id}.jpeg
для ID 1, 2, 3, 4, 5, 7. Тексты используются в учебном локальном каталоге.
Зависимости сохранены из работы №2 и зафиксированы в `pubspec.lock`.
